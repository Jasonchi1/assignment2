3. Two reasons why branches are used in Git

Branches let people work on new features without breaking the main branch.
They also allow different developers to work on things at the same time.

--------------------------------------------------

4. Difference between git log and git status

git log shows the history of commits.

git status shows what files changed and what is ready to commit.

7. OOP Concepts

Inheritance:
A class can use properties or methods from another class.

Polymorphism:
Different objects can use the same function name but behave differently.

Encapsulation:
Data and methods are kept inside a class and protected.

--------------------------------------------------

8. Difference between “Dictator and Lieutenants” and “Integration Manager”

In the dictator model, one main person decides what goes into the project.

In the integration manager model, a maintainer reviews pull requests and merges them.

--------------------------------------------------

9. Why a team of 100 developers might use the “Dictator and Lieutenants” workflow

With many developers it helps organize work better. Lieutenants review code first so the main maintainer doesn’t have to check everything.
