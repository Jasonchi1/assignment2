4. Mention two reasons why branches are used in a Git repository.

Branches let people work on new features without affecting the main
branch. They also let developers work on different tasks at the same time.

5. What is the difference between git log and git status?

git log shows past commits, including who made them and their messages.
git status shows the current branch and which files are staged, changed,
or untracked.

8. What are inheritance, polymorphism, and encapsulation?

(I) Inheritance means a class can reuse and extend another class's
properties and methods. For example, Car can inherit from Vehicle.

(II) Polymorphism means different objects can use the same interface
but behave differently. For example, different vehicle types can have
their own versions of a virtual method.

(III) Encapsulation means keeping data and related methods together in
a class and controlling access to the data, such as using private fields
and public methods.

9. What is the main difference between the Dictator and Lieutenants
workflow and the Integration Manager workflow?

In the Integration Manager workflow, one maintainer directly combines
developers' changes. In the Dictator and Lieutenants workflow,
lieutenants first combine changes from smaller groups and handle their
conflicts. The dictator then combines the lieutenants' work and updates
the official repository.

10. How would a team of 100 developers benefit from Dictator and
Lieutenants instead of the Centralized workflow?

Instead of everyone pushing to one shared repository, developers work
in smaller groups with lieutenants handling their changes and conflicts.
This spreads out the work and lets groups make progress at the same
time. The dictator only needs to combine the lieutenants' work rather
than handle every developer's changes directly.
